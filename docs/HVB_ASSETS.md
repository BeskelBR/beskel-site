# Política de assets — Site público HVB

## Regra operacional

Todo arquivo de imagem aprovado para uso no site público do HVB deve ser incorporado ao repositório na branch `hvb-site-dev` e referenciado a partir do próprio projeto.

Não depender de caminhos locais, anexos temporários do chat ou URLs transitórias para assets que fazem parte da interface publicada.

## Estrutura

- Logos oficiais: `assets/hvb/brand/`
- Fotografias reais: `assets/hvb/photos/`
- Ícones próprios: `assets/hvb/icons/`

## Marca

Usar somente arquivos oficiais do HVB. Não redesenhar nem aproximar a marca.

## Fotografias

Enquanto uma fotografia real ainda não tiver sido fornecida, manter o placeholder `FOTO REAL` com o alvo da fotografia. Quando o arquivo for fornecido e aprovado, fazer upload para a branch e substituir o placeholder pela referência ao asset versionado.
