# GitHub — primeiro envio pelo Visual Studio Code

1. Abra esta pasta no VS Code.
2. Abra `Source Control` na barra lateral.
3. Clique em `Initialize Repository`.
4. Escreva a mensagem `Publicação inicial do site BESKEL`.
5. Clique em `Commit`.
6. Clique em `Publish Branch`.
7. Selecione sua conta GitHub e escolha repositório público ou privado.
8. Confirme que a branch principal se chama `main`.

## Atualizações futuras
Após editar o site:
1. salve os arquivos;
2. abra `Source Control`;
3. escreva uma mensagem objetiva;
4. clique em `Commit`;
5. clique em `Sync Changes`.

A integração GitHub + Cloudflare Pages publicará a nova versão automaticamente.
