## Divergência com `hvb-sistema-dev`

A inspeção somente leitura mostrou que o módulo `terminal` atual do Sistema ainda implementa a arquitetura anterior:

```text
etiqueta → leitura → retirada pelo terminal → transação de estoque
```

O Terminal v2 não deve regredir para esse contrato.

Integração real fica bloqueada até o módulo do Sistema evoluir para:

```text
WithdrawalOrder
+ Auth challenge/evidence/session
+ AccessSession
+ access events
+ picking/fulfillment fora do Terminal
```
